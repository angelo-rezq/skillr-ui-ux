## The product

Skillr serves two kinds of users from the first screen:

- **Looking for a specialist** — place any type of order and search for a performer.
- **I want to find a job** — search and execute orders in your field of activity.

The design keeps the split simple: one role-selection screen, then a tailored flow for each side of the marketplace.

## What's inside

- **Role selection** — the entry point that routes users to the right experience.
- **Sign-up** — name, Egyptian mobile number with country picker, and a password field with live rule validation (letter, number, special character, minimum length).
- **Verification** — 4-digit OTP screen with a native keypad.
- **Login & recovery** — returning-user login and a complete forgot-password flow.
- **Clean visual system** — light, minimal screens with a single confident accent color and generous whitespace.
